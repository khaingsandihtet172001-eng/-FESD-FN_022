# FESD-FN-XXX — Final Lab

Angular + Bootstrap 5 user registration application.

## 1. Project name
Replace `XXX` with the last three digits of your student ID everywhere the project name appears.

## 2. Run
```bash
npm install
npm start
```
Then open the local URL shown by Angular CLI.

## 3. Test
```bash
npm test
```
The unit tests cover TC-01 through TC-10 from the exam.

For the required `test-report` evidence, run the tests and take screenshots of the successful test results, then save them inside `test-report/`.

## 4. Requirements covered
- Angular front-end application
- Bootstrap 5.x responsive UI
- Class-based `User` model
- `getAge()` based on date of birth
- Required fields
- Email validation
- 8–15 character password
- YYYY-MM-DD date validation
- HTTP 201 success alert
- HTTP 422 duplicate email
- HTTP 400 non-numeric telephone
- HTTP 500 exception handling
- Responsive user table
- Full Name concatenation
- Dynamic age display
- Sample data
- Unit tests TC-01 to TC-10
- No `node_modules` included
